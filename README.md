# Guia do Usuário CentralGov

Guia interativo para quem solicita e acompanha serviços da SPU na CentralGov, da busca do serviço ao acompanhamento da solicitação, com as telas reais do sistema.

- **`index.html`**: a página do guia.
- **`imagens/`**: telas do sistema e o logo gov.br/CentralGov (PNG).
- **`.nojekyll`**: arquivo vazio que faz o GitHub Pages servir os arquivos como estão.

## Publicar no GitHub Pages
1. Suba esta pasta para um repositório.
2. Em **Settings → Pages**, escolha *Deploy from a branch*, branch `main`, pasta `/ (root)`.
3. O guia fica em `https://<usuario>.github.io/<repositorio>/`.
